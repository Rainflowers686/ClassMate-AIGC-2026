# Real Device Test Manual - 1.14.10 / 123

## A. 旧课程打开修复

1. 打开一个旧版本导入的课程。
2. 查看课程总结、相关知识点和复习计划。
3. 预期：标题不再出现“同学们注意 / 重点来了 / 大家记一下 / 作业截图上传”等课堂提示语；如果材料不足，显示需要修正 OCR 或补充资料。

## B. 微测入口一致性

1. 从“复习计划 -> 本课知识点复习 -> 查看证据”进入微测。
2. 回到课程，从“知识点时间线 -> 开始微测”进入。
3. 预期：两个入口使用同一批 evidence-bound questions；不再出现证据页有题但课程入口无题。

## C. 旧垃圾题过滤

1. 使用包含课堂提示语和学科内容的旧课程。
2. 开始微测。
3. 预期：题目围绕具体学科知识点，含知识点标题、证据摘录和答案详解；“与课程无关”等坏选项不展示。

## D. 完成练习

1. 完成全部题目并点击“完成练习”。
2. 预期：仍停留在练习页，显示已完成题数、正确/错误数量、相关知识点和复习写入状态。
3. 只有点击“返回课程”或“返回复习计划”才离开。

## E. BlueLM/qwen 回归

1. 保持 1.14.9 的 BlueLM/qwen3.5-plus 设置。
2. 预期：用户只看到“蓝心 / 蓝心大模型”，不看到底层模型名或 reasoning_content。
3. 无配置时本地 fallback 可用，但不冒充 BlueLM。
