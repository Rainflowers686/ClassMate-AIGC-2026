# Poster Copy and Layout - ClassMate 1.14.18

## Title

ClassMate - 把课堂资料变成可复习、可追溯、可练习的学习闭环

## Subtitle

面向高校学生的 AIGC 学习助手：资料输入 -> 知识点 -> 证据 -> 微测 -> 复习计划 -> AI 精修导出

## Three Selling Points

1. 多模态资料导入：图片、文本、文件、录音进入统一资料篮。
2. 证据绑定学习：每个知识点和练习题都追溯到课程证据。
3. 自动微测闭环：提交材料后自动准备练习，完成后更新复习计划。
