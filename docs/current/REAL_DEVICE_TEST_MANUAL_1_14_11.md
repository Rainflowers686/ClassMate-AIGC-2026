## B. OCR 原文保护

1. 使用类似文本：“同学们注意，重点来了。下面看牛顿第二定律，公式 F=ma。”
2. 检查 OCR 草稿、资料篮和 evidence 预览。
3. 预期：OCR 原文不被学科过滤缩短；公式、题号、单位和项目符号保留；低质量时提示人工检查。

## C. fresh 课程生成

2. 查看课程总结、相关知识点、知识点时间线和复习计划。
3. 预期：知识点围绕“牛顿第二定律 / 加速度 / 合外力 / 质量 / F=ma”等学科内容；“同学们注意 / 重点来了 / 大家记一下 / 作业截图上传”不作为标题或复习任务。

## D. 微测入口一致性

1. 从课程知识点时间线点击“开始微测”。
2. 从复习计划或证据页进入微测。
3. 预期：两个入口使用同一批 evidence-bound questions；如果暂无题，会基于 accepted knowledge + evidence 生成，不展示旧空路径。

## E. 完成练习

1. 做完当前微测。
2. 点击完成或进入最后一题后的下一步。
3. 预期：仍停留在练习页，显示完成摘要；只有点击“返回课程”等显式按钮才离开。
